One funny single-line excuse a developer gives when code breaks in production. The $3 reward is split across the top 10 places, and an AI judge compares the excuses head to head in blind pairwise rounds — so this entry aims to land fast, sound like something a developer would actually say, and turn a worn excuse into a confession:

> Production broke because the only test that covered it was marked 'skip' — by me, in 2021, with a comment that just says 'later'.

## How it works

`main.ts` (Node 22, stdlib only, deterministic) writes that line to `$MAKEFUN_OUTPUT_DIR/entry.txt` — the same text on every run, no network calls, no randomness.
